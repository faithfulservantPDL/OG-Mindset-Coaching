# OG-Mindset-Coaching

Landingpage für **OG Mindset Coaching** — mentales und geistliches Coaching mit Ephraim.

## Aufbau

- `index.html` — die komplette Seite (HTML, CSS und JavaScript in einer Datei, keine Build-Tools nötig)
- `assets/` — Bilder, die von der Seite referenziert werden

## Lokal ansehen

```bash
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```

Oder `index.html` direkt im Browser öffnen.

## Bilder ersetzen

In `assets/` liegen aktuell **Platzhalter**. Ersetze sie durch die echten Dateien (gleiche Dateinamen, gleiche Seitenverhältnisse):

| Datei | Inhalt | Seitenverhältnis |
| --- | --- | --- |
| `assets/logo.png` | Logo/Wortmarke (PNG mit Transparenz) | querformatig, wird 34–36 px hoch angezeigt |
| `assets/hero.jpg` | Hero-Foto von Ephraim | 4:5 (z. B. 1100 × 1375) |
| `assets/about.jpg` | Porträt für „Über mich“ | 3:4 (z. B. 1000 × 1333) |
